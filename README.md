# 权衡

面向持有上市公司股票期权职场人的银行 AI 智能体（FinTechathon 2026 国内人工智能赛道参赛作品）。

对话为唯一主入口：意图理解 → 工具执行 → 权限闸门（绿/黄/红三级）→ 追加式审计；内置股权激励税务测算引擎（政策参数见 `data/tax-policy.json`，逐条溯源至税务总局文件）。

## 运行

零外部依赖，需要 Node.js ≥ 20：

```bash
node server/app.js        # 打开 http://localhost:4173
node --test               # 运行全部测试
```

强验证演示码：`246810`。

## 结构

- `server/` 模拟银行核心、权限闸门、测算引擎、Agent 层、HTTP 服务
- `web/` 前端单页（对话 + 我的银行面板）
- `data/` 种子数据与已核验的税务政策参数
- `docs/` 接口契约、政策核查报告、验收用例
