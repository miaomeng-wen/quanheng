# 中国境内上市公司股权激励（股票期权）个人所得税政策研究报告

**报告性质**：税务政策核查报告（基于官方来源检索核实）
**核查完成日期**：2026年10月27日
**检索来源**：以国家税务总局政策法规库（fgk.chinatax.gov.cn）、财政部官网（mof.gov.cn）及省级税务局官网（广东省税务局、上海市税务局等官方网站转载的总局文件）为准；所有结论均附官方原文摘录与链接。检索工具：AnySearch。

**总体结论摘要**：

1. 股权激励单独计税现行依据为**财政部 税务总局公告2023年第25号**，执行至**2027年12月31日**；
2. 行权环节按"工资、薪金所得"计税，应纳税所得额与税额公式源自**财税〔2005〕35号**（并经财税〔2018〕164号、2023年第25号公告调整为现行口径）；同一纳税年度两次以上取得股权激励的，**合并计算**；
3. 境内上市公司股权激励可经备案在**不超过36个月**期限内缴纳税款，依据为**财政部 税务总局公告2024年第2号**（该公告同时废止了财税〔2016〕101号原"12个月"规定）；
4. 行权后转让流通股暂免个人所得税（财税字〔1998〕61号）；转让限售股按"财产转让所得"20%征税（财税〔2009〕167号、财税〔2010〕70号，并经**2026年第26号公告**最新规范）；股息红利适用差别化政策（财税〔2015〕101号）；
5. 计税时点划分：授予环节一般不计税、行权环节计税、转让环节按财产转让征免规定处理、持股分红按股息红利处理，框架源自**财税〔2005〕35号**第二条。

### 1.3 适用条件

依据2023年第25号公告第一条（上述摘录），适用单独计税须同时满足：

1. **纳税人身份**：居民个人；
2. **激励类型**：股票期权、股票增值权、限制性股票、股权奖励等股权激励；
3. **基础条件文件**：符合财税〔2005〕35号、财税〔2009〕5号、财税〔2015〕116号第四条、财税〔2016〕101号第四条第（一）项规定的相关条件。

**基础条件文件要点（官方原文核实）**：

- **财税〔2005〕35号**（文号：财税〔2005〕35号；成文日期：2005-03-28；自2005年7月1日起执行；链接：https://fgk.chinatax.gov.cn/zcfgk/c102416/c5203004/content.html ）规定适用对象为"企业员工（包括在中国境内有住所和无住所的个人）参与企业股票期权计划"；
- **国税函〔2009〕461号**（文号：国税函〔2009〕461号；成文日期：2009-08-24；链接：https://fgk.chinatax.gov.cn/zcfgk/c100012/c5194079/content.html ）第七条明确了适用主体范围与排除情形（原文摘录见 1.4）。
- **备案要求**（与"单独计税"直接相关的报送义务）：
  - 财税〔2005〕35号第五条第（三）项（原文）："实施股票期权计划的境内企业，应在股票期权计划实施之前，将企业的股票期权计划或实施方案、股票期权协议书、授权通知书等资料报送主管税务机关；应在员工行权之前，将股票期权行权通知书和行权调整通知书等资料报送主管税务机关。"
  - 财税〔2009〕5号第四条（原文）："实施股票增值权计划或限制性股票计划的境内上市公司，应在向中国证监会报备的同时，将企业股票增值权计划、限制性股票计划或实施方案等有关资料报送主管税务机关备案。"

### 1.4 不适用优惠计税方法的情形（国税函〔2009〕461号第七条第（二）项，原文）

> "（二）具有下列情形之一的股权激励所得，不适用本通知规定的优惠计税方法，直接计入个人当期所得征收个人所得税：
> 1.除本条第(一)项规定之外的集团公司、非上市公司员工取得的股权激励所得；
> 2.公司上市之前设立股权激励计划，待公司上市后取得的股权激励所得；
> 3.上市公司未按照本通知第六条规定向其主管税务机关报备有关资料的。"

注：国税函〔2009〕461号页面显示"已修改"，其第七条第（一）项括号内"间接控股限于上市公司对二级子公司的持股"已根据国家税务总局公告2011年第27号自2011年5月1日起废止；其余条款未见废止标注。

### 1.5 "境内上市公司"的范围

- 2023年第25号公告本身未限定境内/境外上市公司，其沿用的财税〔2005〕35号、财税〔2009〕5号均明确适用于"上市公司（含境内、外上市公司）"；国税函〔2009〕461号同样明确"上市公司（含境内、外上市公司）"。
- **财税〔2016〕101号**（成文日期：2016-09-20；链接：https://fgk.chinatax.gov.cn/zcfgk/c102416/c5203666/content.html ）第五条规定："适用本通知第二条规定的上市公司是指其股票在上海证券交易所、深圳证券交易所上市交易的股份有限公司。"（注：该第二条已由2024年第2号公告废止，详见本报告第三部分，但该定义条款位于第五条，未被废止。）
- **财政部 税务总局公告2024年第2号**第二条单独定义："本公告所称境内上市公司是指其股票在上海证券交易所、深圳证券交易所、北京证券交易所上市交易的股份有限公司。"（适用于36个月延期纳税政策，见第三部分。）

## 二、行权环节计算公式：应纳税所得额与税额的计算口径

### 2.1 现行计税框架

现行口径 = **应纳税所得额按财税〔2005〕35号等基础文件确定** + **应纳税额按2023年第25号公告公式（全额单独适用综合所得税率表）计算**。

### 2.2 股票期权行权环节应纳税所得额（财税〔2005〕35号第二条第（二）项，原文）

> "（二）员工行权时，其从企业取得股票的实际购买价（施权价）低于购买日公平市场价（指该股票当日的收盘价，下同）的差额，是因员工在企业的表现和业绩情况而取得的与任职、受雇有关的所得，应按'工资、薪金所得'适用的规定计算缴纳个人所得税。
> 对因特殊情况，员工在行权日之前将股票期权转让的，以股票期权的转让净收入，作为工资薪金所得征收个人所得税。
> 员工行权日所在期间的工资薪金所得，应按下列公式计算工资薪金应纳税所得额：
> **股票期权形式的工资薪金应纳税所得额=（行权股票的每股市场价-员工取得该股票期权支付的每股施权价）×股票数量**"

其中"公平市场价格"的确定，依据**国家税务总局公告2016年第62号**第一条第（四）款（文号：国家税务总局公告2016年第62号；成文日期：2016-09-28；链接：https://fgk.chinatax.gov.cn/zcfgk/c100012/c5194681/content.html ）：

> "1.上市公司股票的公平市场价格，按照取得股票当日的收盘价确定。取得股票当日为非交易日的，按照上一个交易日收盘价确定。"

### 2.3 行权环节应纳税额的计算（现行口径，2023年第25号公告，原文）

> "应纳税额＝股权激励收入×适用税率－速算扣除数"

适用税率和速算扣除数以股权激励收入（即上述应纳税所得额，见本报告"引擎参数清单"）对照**个人所得税税率表一（综合所得适用）**确定（税率表见本报告末节）。

### 2.4 历史公式（2018年12月31日前口径，供测算引擎做历史区间回溯时参考）

财税〔2005〕35号第四条第（一）项（原文）：

> "应纳税额=（股票期权形式的工资薪金应纳税所得额÷规定月份数×适用税率-速算扣除数）×规定月份数
> 上款公式中的规定月份数，是指员工取得来源于中国境内的股票期权形式工资薪金所得的境内工作期间月份数，长于12个月的，按12个月计算；上款公式中的适用税率和速算扣除数，以股票期权形式的工资薪金应纳税所得额除以规定月份数后的商数，对照《国家税务总局关于印发〈征收个人所得税若干问题〉的通知》（国税发〔1994〕89号）所附税率表确定。"

**注意**：财税〔2018〕164号第二条（上海市税务局页面原文）规定新税法下的现行公式为"应纳税额＝股权激励收入×适用税率－速算扣除数"（不再按"规定月份数"摊分）；且根据财税〔2018〕164号，国税函〔2006〕902号第七条、第八条自2019年1月1日起废止（总局政策库国税函〔2006〕902号页面标注，原文摘录见2.5）。

### 2.5 同一纳税年度内两次以上（含两次）股权激励的合并计算

**现行规定（2023年第25号公告第二条，原文）**：

> "二、居民个人一个纳税年度内取得两次以上（含两次）股权激励的，应合并按本公告第一条规定计算纳税。"

即：将一个纳税年度内各次股权激励收入**合并为一次股权激励收入**，全额单独适用综合所得税率表，按公式"应纳税额＝合并后股权激励收入×适用税率－速算扣除数"计算。

**历史规定（国税函〔2006〕902号第七条、第八条，自2019年1月1日起已废止，供历史回溯参考）**（原文摘录）：

> "七、员工以在一个公历月份中取得的股票期权形式工资薪金所得为一次。员工在一个纳税年度中多次取得股票期权形式工资薪金所得的，其在该纳税年度内首次取得股票期权形式的工资薪金所得应按财税〔2005〕35号文件第四条第（一）项规定的公式计算应纳税款；本年度内以后每次取得股票期权形式的工资薪金所得，应按以下公式计算应纳税款：
> 应纳税款=（本纳税年度内取得的股票期权形式工资薪金所得累计应纳税所得额÷规定月份数×适用税率-速算扣除数）×规定月份数-本纳税年度内股票期权形式的工资薪金所得累计已纳税款"

国税函〔2009〕461号第四条第（二）项（原文）亦规定：

> "（二）个人在纳税年度内两次以上(含两次)取得股票期权、股票增值权和限制性股票等所得,包括两次以上(含两次)取得同一种股权激励形式所得或者同时兼有不同股权激励形式所得的，上市公司应将其纳税年度内各次股权激励所得合并，按照《国家税务总局关于个人股票期权所得缴纳个人所得税有关问题的补充通知》（国税函〔2006〕902号）第七条、第八条所列公式计算扣缴个人所得税。"

国家税务总局公告2016年第62号第一条第（三）项（现行征管补充，原文）：

> "员工以在一个公历月份中取得的股票（权）形式工资薪金所得为一次。员工取得符合条件、实行递延纳税政策的股权激励，与不符合递延纳税条件的股权激励分别计算。
> 员工在一个纳税年度中多次取得不符合递延纳税条件的股票（权）形式工资薪金所得的，参照《国家税务总局关于个人股票期权所得缴纳个人所得税有关问题的补充通知》（国税函〔2006〕902号）第七条规定执行。"

（说明：62号公告上述条款针对非上市公司递延纳税与不递延部分分别计算的情形作出"参照902号文第七条"的衔接；在上市公司单独计税场景下，计算口径以2023年第25号公告第二条"合并按第一条规定计算纳税"为准。）

### 2.6 股票增值权、限制性股票的应纳税所得额公式（与股票期权并列的股权激励形式）

国税函〔2009〕461号（原文）：

> 限制性股票："应纳税所得额=（股票登记日股票市价+本批次解禁股票当日市价）÷2×本批次解禁股票份数-被激励对象实际支付的资金总额×（本批次解禁股票份数÷被激励对象获取的限制性股票总份数）"

## 四、行权后转让环节与股息红利

### 4.1 个人转让境内上市公司股票（流通股）：暂免征收

**《财政部 国家税务总局关于个人转让股票所得继续暂免征收个人所得税的通知》（财税字〔1998〕61号）**

- **发文日期**：1998年3月30日（一说1998-03-30发布）
- **有效期/状态**：全文有效，持续执行（第三方转载页面及地方税务局转载均标注"全文有效"；税务总局政策库直接链接未检索到，以广东省税务局转载链接为准）
- **官方链接**：https://guangdong.chinatax.gov.cn/gdsw/zjfg/2011-02/23/content_6457485b07544d54a1fb07a99d1eb869.shtml （国家税务总局广东省税务局网站转载）
- **关键原文摘录**：

> "为了配合企业改制，促进股票市场的稳健发展，经报国务院批准，从1997年1月1日起，对个人转让上市公司股票取得的所得继续暂免征收个人所得税。"

**配套条文**：财税〔2005〕35号第四条第（二）项（原文）：

> "个人将行权后的境内上市公司股票再行转让而取得的所得，暂不征收个人所得税；个人转让境外上市公司的股票而取得的所得，应按税法的规定计算应纳税所得额和应纳税额，依法缴纳税款。"

**要点提示**：暂免范围是"从公开发行和转让市场取得的上市公司股票"（即二级市场流通股）；员工行权取得的股票若属于**限售股**（如IPO前的限售股、定向增发形成等），不适用暂免，按限售股政策征税（见4.2）。此外，若同时持有限售股与流通股，按"**限售股优先**"原则视同先转让限售股（财税〔2009〕167号第六条，原文："纳税人同时持有限售股及该股流通股的，其股票转让所得，按照限售股优先原则，即：转让股票视同为先转让限售股，按规定计算缴纳个人所得税。"）。

### 4.2 个人转让限售股：按"财产转让所得"20%征税

**《财政部 国家税务总局 证监会关于个人转让上市公司限售股所得征收个人所得税有关问题的通知》（财税〔2009〕167号）**

- **官方链接**：https://fgk.chinatax.gov.cn/zcfgk/c102416/c5203570/content.html （国家税务总局政策法规库）
- **关键原文摘录**：

> "一、自2010年1月1日起，对个人转让限售股取得的所得，按照'财产转让所得'，适用20%的比例税率征收个人所得税。
> 二、本通知所称限售股，包括：
> 1.上市公司股权分置改革完成后股票复牌日之前股东所持原非流通股股份，以及股票复牌日至解禁日期间由上述股份孳生的送、转股（以下统称股改限售股）；

> 三、个人转让限售股，以每次限售股转让收入，减除股票原值和合理税费后的余额，为应纳税所得额。即：
> **应纳税所得额＝限售股转让收入－（限售股原值+合理税费）**
> **应纳税额 = 应纳税所得额×20%**
> 本通知所称的限售股转让收入，是指转让限售股股票实际取得的收入。限售股原值，是指限售股买入时的买入价及按照规定缴纳的有关费用。合理税费，是指转让限售股过程中发生的印花税、佣金、过户费等与交易相关的税费。
> 如果纳税人未能提供完整、真实的限售股原值凭证的，不能准确计算限售股原值的，主管税务机关一律按限售股转让收入的15%核定限售股原值及合理税费。"

**持股期限计算**：财税〔2015〕101号本身未重复，财税〔2012〕85号及《关于延续实施全国中小企业股份转让系统挂牌公司股息红利差别化个人所得税政策的公告》（总局政策库链接：https://fgk.chinatax.gov.cn/zcfgk/c102416/c5232671/content.html ）明确"个人转让股票时，按照先进先出的原则计算持股期限"。

**税率依据**：《中华人民共和国个人所得税法》第三条第（三）项（总局政策库链接：https://fgk.chinatax.gov.cn/zcfgk/c100009/c5193028/content.html ，原文）：

> "（三）利息、股息、红利所得，财产租赁所得，财产转让所得和偶然所得，适用比例税率，税率为百分之二十。"

**关联新政策提示**：自2026年9月1日起，外籍个人从外商投资企业取得的股息红利所得不再免征、按20%征收（财政部 税务总局公告2026年第27号，链接：https://fgk.chinatax.gov.cn/zcfgk/c102416/c5252107/content.html ）。该政策不影响境内居民个人适用差别化政策，但涉及外籍激励对象的分红测算时应纳入考虑。

## 五、股票期权从授权到行权的完整计税时点划分

框架性依据：**财税〔2005〕35号第二条**（原文摘录已在2.2引用，完整划分如下）。

| 环节 | 是否计税 | 所得项目 | 计税依据与要点 | 时点/规则 |
|---|---|---|---|---|
| **① 授予（授权）** | **一般不计税** | — | 财税〔2005〕35号第二条第（一）项："员工接受实施股票期权计划企业授予的股票期权时，除另有规定外，一般不作为应税所得征税。" | 授予日 |
| **①' 授予可公开交易的股票期权（例外）** | **计税** | 工资、薪金所得 | 国税函〔2006〕902号第六条第（一）项：按授权日股票期权市场价格作为授权日所在月份工资薪金所得，按财税〔2005〕35号第四条第（一）项规定计算缴纳 | 授权日 |
| **② 行权前转让期权（特殊情况）** | **计税** | 工资、薪金所得 | 财税〔2005〕35号第二条第（二）项："对因特殊情况，员工在行权日之前将股票期权转让的，以股票期权的转让净收入，作为工资薪金所得征收个人所得税。"（902号文第二条：转让净收入一般指转让收入，折价购入的可扣除支付价款） | 期权转让时 |
| **③ 行权** | **计税（核心环节）** | 工资、薪金所得 | 财税〔2005〕35号第二条第（二）项：施权价低于行权日公平市场价（当日收盘价）的差额，按"工资、薪金所得"计税。现行应纳税额＝股权激励收入×适用税率－速算扣除数（2023年第25号公告）；可经备案在不超过36个月内缴纳税款（2024年第2号公告） | 行权日（纳税义务发生时间） |
| **③' 股票增值权兑现（参考）** | **计税** | 工资、薪金所得 | 国税函〔2009〕461号第五条第（一）项："股票增值权个人所得税纳税义务发生时间为上市公司向被授权人兑现股票增值权所得的日期" | 兑现日 |
| **③'' 限制性股票解禁（参考）** | **计税** | 工资、薪金所得 | 国税函〔2009〕461号第五条第（二）项："限制性股票个人所得税纳税义务发生时间为每一批次限制性股票解禁的日期" | 每批次解禁日 |
| **④ 行权后转让股票** | **视股票性质** | 财产转让所得 | 财税〔2005〕35号第二条第（三）项："员工将行权后的股票再转让时获得的高于购买日公平市场价的差额，是因个人在证券二级市场上转让股票等有价证券而获得的所得，应按照'财产转让所得'适用的征免规定计算缴纳个人所得税。"具体征免：流通股暂免（财税字〔1998〕61号、财税〔2009〕167号第八条）；限售股按20%征收（财税〔2009〕167号、2026年第26号公告） | 转让时 |
| **⑤ 持股期间取得股息红利** | **计税（差别化）** | 利息、股息、红利所得 | 财税〔2005〕35号第二条第（四）项："员工因拥有股权而参与企业税后利润分配取得的所得，应按照'利息、股息、红利所得'适用的规定计算缴纳个人所得税。"适用财税〔2015〕101号差别化政策（持股超1年免税；1个月以内全额；1个月至1年减按50%；税率20%） | 分派时（持股1年以内为转让时代扣） |

**扣缴义务人**（财税〔2005〕35号第五条第（一）项，原文）：

> "实施股票期权计划的境内企业为个人所得税的扣缴义务人，应按税法规定履行代扣代缴个人所得税的义务。"

**自行申报**（财税〔2005〕35号第五条第（二）项，原文）：

> "员工从两处或两处以上取得股票期权形式的工资薪金所得和没有扣缴义务人的，该个人应在个人所得税法规定的纳税申报期限内自行申报缴纳税款。"

### 6.2 行权环节（工资薪金所得）公式

**现行（2019-01-01起，财税〔2018〕164号确立、2023年第25号公告延续）**：

```
应纳税所得额（股权激励收入）=（行权股票每股市场价 − 每股施权价）× 股票数量
    [财税〔2005〕35号二（二）；市场价=行权日收盘价（国税函〔2009〕461号/2016年62号公告口径）]

应纳税额 = 股权激励收入 × 适用税率 − 速算扣除数
    [财政部 税务总局公告2023年第25号第一条]
```

**同一年度多次取得（含两种以上形式）**：

```
合并股权激励收入 = Σ 同一纳税年度内各次股权激励收入（各次先按上述口径单笔计算应纳税所得额）
应纳税额 = 合并股权激励收入 × 适用税率 − 速算扣除数
    [财政部 税务总局公告2023年第25号第二条："应合并按本公告第一条规定计算纳税"]
```

**历史口径（2005-07-01至2018-12-31，测算引擎回溯历史数据时使用）**：

```
应纳税额 =（股票期权形式的工资薪金应纳税所得额 ÷ 规定月份数 × 适用税率 − 速算扣除数）× 规定月份数
    [财税〔2005〕35号四（一）；规定月份数=境内工作期间月份数，长于12个月按12个月]

同一年度第n次取得（n≥2）：
应纳税款 =（累计应纳税所得额 ÷ 规定月份数 × 适用税率 − 速算扣除数）× 规定月份数 − 累计已纳税款
    [国税函〔2006〕902号第七条（自2019-01-01废止，历史期间适用）]

规定月份数不同时加权：规定月份数 = Σ(各次应纳税所得额×该次境内工作期间月份数) / Σ(各次应纳税所得额)，上限12个月
    [国税函〔2006〕902号第八条（自2019-01-01废止，历史期间适用）]
```

### 6.3 限制性股票、股票增值权应纳税所得额公式（现行）

```
限制性股票：
应纳税所得额 =（股票登记日股票市价 + 本批次解禁股票当日市价）÷ 2 × 本批次解禁股票份数
              − 被激励对象实际支付资金总额 ×（本批次解禁股票份数 ÷ 获取的限制性股票总份数）
    [国税函〔2009〕461号三；市价指当日收盘价]

股票增值权：
某次行权应纳税所得额 =（行权日股票价格 − 授权日股票价格）× 行权股票份数
    [国税函〔2009〕461号二]
```

### 6.4 转让环节（财产转让所得，税率20%）公式

```
流通股（从公开发行和转让市场取得）：暂免征收个人所得税
    [财税字〔1998〕61号；财税〔2009〕167号第八条]

限售股：
应纳税所得额 = 限售股转让收入 −（限售股原值 + 合理税费）
应纳税额 = 应纳税所得额 × 20%
    [财税〔2009〕167号三；2026年第26号公告第一条]
原值无法准确提供：按转让收入的15%核定原值及合理税费（2026年第26号公告实施前登记情形）；
    公告实施后初始登记未申报成本原值的，按转让收入全额预扣、清算申报多退少补
    [财税〔2009〕167号三；财政部 税务总局 中国证监会公告2026年第26号二、三]
限售股与流通股并存：视同先转让限售股（限售股优先原则）
    [财税〔2009〕167号六]

同时持有限售股+流通股时送转股成本调整：按送、转、缩股比例调整限售股成本原值
    [2026年第26号公告一]
```

### 6.5 股息红利（利息、股息、红利所得，税率20%）公式

```
持股期限 > 1年：暂免征收
1个月以内（含）：应纳税额 = 股息红利所得 × 20%（全额计入）
1个月以上至1年（含）：应纳税额 = 股息红利所得 × 50% × 20% = 股息红利所得 × 10%
    [财税〔2015〕101号一；税率依据：个人所得税法三（三）]

限售股解禁前取得的股息红利：减按50%计入应纳税所得额×20%
解禁后取得的：按持股期限差别化，持股时间自解禁日起计算
    [财税〔2012〕85号四（经财税〔2015〕101号三援引继续适用）]
```

### 6.6 延期纳税（现金流时点参数，不影响税额）

```
境内上市公司（沪深北）股票期权/限制性股票/股权奖励，经备案：
缴税期限 ≤ 自行权（行权/解禁/取得股权奖励）之日起36个月；离职前缴清
    [财政部 税务总局公告2024年第2号一、三；备案：次月15日内报送《上市公司股权激励个人所得税延期纳税备案表》（国家税务总局公告2016年第62号一（五）2，期限已由12个月更新为36个月）]
```
