# 《权衡》技术文档

## 1. 系统概述

《权衡》是面向持有上市公司股票期权职场人的银行 AI 智能体。用户通过自然语言对话办理银行业务：智能体理解意图、规划任务、调用银行工具执行，全程受权限闸门与审计约束。对话是唯一主入口，右侧银行面板实时呈现账户、持仓、卡片、订阅、计划与审计状态。

设计原则：**理解层可以灵活，执行层必须确定。** 意图理解由规则解析与智谱 GLM-4-Flash 大模型兜底组成；所有资金动作只能经工具层与权限闸门执行，金额与账户数据只能来自工具返回值，杜绝编造。

## 3. 核心算法

### 3.1 意图理解与任务规划

- **规则解析（主路径）**：正则与槽位抽取覆盖余额、账单、转账（含中文数字与“5万”等混合写法、手机号收款人）、理财申购/赎回、风险测评、卡片、订阅、AA 平摊、期权测算与备资计划；支持省略句与口语变体，缺参时追问。
- **LLM 兜底（已启用）**：规则未命中时，调用智谱 GLM-4-Flash（OpenAI 兼容端点）将自由文本翻译为受限意图 JSON；输出经意图白名单、槽位类型/范围/枚举校验后才被采纳，任何异常即丢弃并降级。LLM 不直接产生金额结论、不调用工具。
- **任务规划**：复杂目标（如行权备资）被拆为带执行时间的步骤链（定时赎回、每月发薪锁定、到期归集），步骤即计划的线性 DAG；每步执行前由闸门按当时状态复检授权与余额，支持中途取消未执行步骤。

### 3.2 期权行权税务测算引擎

- 输入：股数、行权价、现价情景、是否分批跨年、行权后立即卖出/持有再卖。
- 规则（均附官方出处，见 `docs/policy-research.md`）：行权收入 =（行权日收盘价 − 施权价）× 数量；居民个人取得股票期权按工资薪金所得单独计税（财政部 税务总局公告 2023 年第 25 号，执行至 2027-12-31）；同年多次激励合并计税；符合条件可自登记日起 36 个月内分期缴税（2024 年第 2 号公告，备案制）；行权后转让上市公司股票暂免个税。
- 输出：四种安排（一次/分批 × 立即卖出/持有再卖）的行权款、税额、税后净收益矩阵与备资建议（每月锁定额 + 分批赎回安排）。引擎经独立复算交叉验证（5 个用例结果一致，见 `docs/crosscheck-calc.md`）。

### 3.3 权限闸门

- 分级：绿（纯查询）自动执行；黄（小额转账日累计 ≤1000 元、订阅取消、虚拟卡申请、卡限额调整）须用户明确确认；红（大额转账、理财申购/赎回、挂失/解挂、计划创建）须多因子强验证（演示环境为验证码，架构上可替换人脸/U 盾）。
- **参数绑定**：授权卡生成时对规范化参数计算摘要哈希；执行时重算比对，任何篡改（包括客户端在授权请求里夹带金额字段）都会使绑定失效。
- **执行时复检**：定时步骤与延迟执行在真正执行前重新校验授权有效性、账户状态与余额，不依赖发起时的状态。
- **熔断**：连续验证失败或注入尝试达到阈值后锁定敏感操作，查询类功能不受影响。

## 4. 安全设计（摘要）

幻觉防护（数据只出自工具、回复模板化拼装）、注入防御（输入护栏 + 注入计数与审计）、操作审计（哈希链全量记录决策与执行）、异常熔断、沙箱（全部业务运行于模拟银行环境，无真实资金与真实接口）。详见《安全自评报告》及 `docs/redteam-2026-10-27.md` 红队实测。

## 5. 部署与运行

- 运行环境：Node ≥ 20，零外部依赖；`npm start` 启动，监听 `PORT`（默认 4173）。
- 公网演示：Render 免费 Web Service，仓库推送自动部署，地址 https://quanheng.onrender.com （免费层闲置休眠、重启后演示数据重置，属预期）。
- 模拟时钟：初始 2026-10-27，可经界面“快进”推进，用于演示定时任务、订阅扣费与计划执行。
- LLM 兜底已在公网演示启用：环境变量 `QH_LLM_BASE_URL`、`QH_LLM_API_KEY`、`QH_LLM_MODEL` 指向智谱开放平台（模型 glm-4.5-flash，免费档）；端点不可用或未配置时自动降级为纯规则解析。
