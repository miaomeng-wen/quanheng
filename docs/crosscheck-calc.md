# 股权激励个税测算独立复核

## 复核口径

- 股权激励收入 =（行权日市价 - 行权价）× 数量。
- 应纳税额 = 收入 × 税率 - 速算扣除数。
- 同一纳税年度的多次激励合并计税；已有激励收入后的本次增量税额 = 合并收入对应税额 - 已有收入对应税额。
- 跨纳税年度的行权分别计税，不合并为同一纳税年度收入。
- 行权后转让流通股暂免个税，因此不再扣除转让环节税款。
- 本报告的“净到手”按题给引擎口径，指股权激励收入减去相关税额，不额外扣除行权成本或其他未给费用。

## 用例1：一次行权并立即卖出

**独立计算**

1. 股权激励收入 =（28 - 12）× 10,000 = 160,000 元。
2. 160,000 元适用 20% 税率，速算扣除数为 16,920 元。
3. 应纳税额 = 160,000 × 20% - 16,920 = 32,000 - 16,920 = **15,080 元**。
4. 净到手 = 160,000 - 15,080 = **144,920 元**。
5. 立即卖出流通股不另计个税。

**对比结论**

- 税额：独立结果为 15,080 元，引擎输出 15,080 元，**一致**。
- 净到手：独立结果为 144,920 元，引擎输出 144,920 元，**一致**。

## 用例2：分两批各5,000股，跨两个纳税年度

**独立计算**

1. 每批股权激励收入 =（28 - 12）× 5,000 = 80,000 元。
2. 两批分别属于不同纳税年度，因此每年均单独以 80,000 元计税。
3. 每年 80,000 元适用 10% 税率，速算扣除数为 2,520 元。
4. 每年税额 = 80,000 × 10% - 2,520 = 8,000 - 2,520 = 5,480 元。
5. 两年合计税额 = 5,480 × 2 = **10,960 元**。

**对比结论**

- 合计税额：独立结果为 10,960 元，引擎输出 10,960 元，**一致**。
- 引擎未给出本例净到手，故无对应净到手数字可比较；按收入合计 160,000 元减合计税额计算，净到手为 **149,040 元**。

## 用例3：同年已有激励收入100,000元，再行权用例1的期权

**独立计算**

1. 本次股权激励收入 =（28 - 12）× 10,000 = 160,000 元。
2. 同年合并激励收入 = 100,000 + 160,000 = 260,000 元。
3. 已有 100,000 元适用 10% 税率、速算扣除数 2,520 元，其对应税额 = 100,000 × 10% - 2,520 = 7,480 元。
4. 合并收入 260,000 元适用 20% 税率、速算扣除数 16,920 元，合并税额 = 260,000 × 20% - 16,920 = 52,000 - 16,920 = 35,080 元。
5. 本次增量税额 = 35,080 - 7,480 = **27,600 元**。

**对比结论**

- 本次增量税额：独立结果为 27,600 元，引擎输出 27,600 元，**一致**。
- 引擎未给出本例净到手；按本次收入减本次增量税额计算，本次净到手为 **132,400 元**。

## 用例4：市价22.4元，其余同用例1

**独立计算**

1. 股权激励收入 =（22.4 - 12）× 10,000 = 10.4 × 10,000 = 104,000 元。
2. 104,000 元适用 10% 税率，速算扣除数为 2,520 元。
3. 应纳税额 = 104,000 × 10% - 2,520 = 10,400 - 2,520 = **7,880 元**。
4. 净到手 = 104,000 - 7,880 = **96,120 元**。

**对比结论**

- 税额：独立结果为 7,880 元，引擎输出 7,880 元，**一致**。
- 引擎未给出本例净到手，故无对应净到手数字可比较；独立结果为 **96,120 元**。

## 用例5：不行权

**独立计算**

不行权则不产生股权激励收入，也无本次行权税额，净到手 = **0 元**。

**对比结论**

- 净到手：独立结果为 0 元，引擎输出 0 元，**一致**。

## 总评

5 个用例中，引擎给出的全部数字均与独立计算一致，未发现错误。**就本题规则及这 5 个用例覆盖的情况而言，引擎数字可以信赖。** 该结论仅限于所给场景，不等同于对未测试边界、舍入处理或其他业务规则的全面验证。
