# 测算引擎验收用例（总控手算，待政策核验确认口径后生效）

口径假设（待 docs/policy-research.md 核验确认）：股权激励收入全额单独适用综合所得税率表计税；
同一年度多次激励合并计算。税率表（综合所得年度表）：
≤36,000 → 3%，扣除 0；≤144,000 → 10%，扣除 2,520；≤300,000 → 20%，扣除 16,920；
≤420,000 → 25%，扣除 31,920；≤660,000 → 30%，扣除 52,920；≤960,000 → 35%，扣除 85,920；>960,000 → 45%，扣除 181,920。

## 用例 1：主线基础（一次行权、立即卖出）
- 输入：10,000 股，行权价 12 元，现价情景 28 元，卖价 28 元，当年无其他激励收入。
- 行权成本 = 120,000 元；激励收入 = (28−12)×10,000 = 160,000 元。
- 税额 = 160,000×20% − 16,920 = **15,080 元**。
- 立即卖出净到手 = 160,000 − 15,080 = **144,920 元**（不计费用）。
- 验收点：引擎输出 taxCents = 1,508,000 分；assumptions 含价格情景与政策出处。

## 用例 2：分批跨年（价格不变假设）
- 两批各 5,000 股，分属两个纳税年度，每批收入 80,000 元。
- 每批税额 = 80,000×10% − 2,520 = 5,480 元；合计 **10,960 元**。
- 与用例 1 对比差额 = 4,120 元 — 引擎只能陈述“按假设价格与现行政策计算相差 4,120 元”，不得断言必然节税。

## 用例 3：同年合并计算（审核 §11 的关键用例）
- 输入：priorYearIncentiveIncome = 100,000 元，本次再行权收入 160,000 元（同年）。
- 合并收入 260,000 元 → 税额 = 260,000×20% − 16,920 = 35,080 元。
- 本次增量税额 = 35,080 − (100,000×10% − 2,520 = 7,480) = **27,600 元**。
- 验收点：引擎对“同年第二批”必须按合并口径算出 27,600 元，按单独口径算 15,080 元即为不合格。

## 用例 4：价格情景
- 现价 −20% 情景（22.4 元）：收入 = (22.4−12)×10,000 = 104,000 元 → 税 = 104,000×10% − 2,520 = **7,880 元**。
- 现价低于行权价情景（10 元）：内在价值为负 → 引擎应给出“不行权基线占优”提示，收入按 0 处理、不产生负税。

## 用例 5：不行权基线
- netProceeds = 0；机会成本 = 内在价值（情景价格下），字段齐全。

以上述 5 例全过 + 引擎单测全绿 + dsh 独立复算一致，测算引擎才算验收通过。
